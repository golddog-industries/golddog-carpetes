Perguntas frequentes
Qual a diferença entre o Carpete Âncora e o GoldMoss?+
O Carpete Âncora usa células de vórtice (Mini Hydro-Cyclone) para capturar ouro extrafino — partículas abaixo de 0,1mm que carpetes comuns perdem. O GoldMoss é um carpete vazado para uso em trommels e calhas de maior vazão, retendo ouro pelo princípio de gravidade. O ideal é usar os dois em conjunto: GoldMoss como base e Âncora como camada de alta captação.
Com que frequência devo trocar os carpetes?+
Os carpetes GoldDog são duráveis, mas o desgaste depende do volume de material processado e do tipo de cascalho. Em operações contínuas, inspecione mensalmente. Carpetes desgastados perdem eficiência de captação. Cores podem desbotar mas isso não afeta o desempenho — troque quando o padrão de fibras estiver danificado.
Posso usar o carpete com mercúrio?+
Não recomendamos. Os sistemas GoldDog são projetados para recuperação de ouro 100% sem mercúrio, por processo gravimétrico. O uso de mercúrio além de ilegal em muitas regiões danifica os carpetes e reduz sua eficiência ao longo do tempo.
Os grampos para fixação vêm inclusos?+
Os grampos para fixação dos Carpetes Âncora são vendidos separadamente. Ao solicitar seu orçamento, informe que precisa dos grampos e incluímos no pedido.
Posso comprar somente os carpetes sem o equipamento?+
Sim! Os carpetes são vendidos separadamente para reposição ou para quem já tem outros sistemas de lavagem compatíveis. Entre em contato via WhatsApp para verificar compatibilidade com seu equipamento atual.
